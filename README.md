# Python-mini-projects

Collection of beginner Python projects created for learning and practice.

## Projects

### Calculator Project
A simple calculator built using Python functions and dictionaries. Supports addition, subtraction, multiplication, and division operations.

### Higher Lower Game
A Python-based guessing game where users compare social media follower counts and try to guess who has more followers.

## Technologies Used
- Python
- Functions
- Dictionaries
- Loops
- Random Module
